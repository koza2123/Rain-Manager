
# Rain Manager

Chrome Extension - Manifest V3.

## Features

- Dashboard
- Website URL settings
- Number settings
- Hourly schedule
- Countdown timer
- Activity logs
- Start and Stop buttons

## Installation

1. Extract the project folder.
2. Open chrome://extensions
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the rain-manager folder.

## Important

Website automation is not connected yet.
The target website must be inspected before
adding its integration.
